# Barangay Resident Record Management System (RRMS)

A responsive frontend prototype for a proposed digital platform designed to support barangay resident and household information management.

## Overview

The Barangay Resident Record Management System is an academic group project developed to present a proposed digital approach to organizing resident information and simplifying registration through a web-based interface.

## Features

- Responsive landing page
- Interactive navigation menu
- Login interface with demonstration credentials
- Resident registration form
- Client-side form validation
- Interactive video presentation
- Mobile-friendly layout

## Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, responsive layouts, and animations
- **JavaScript** – Interactive elements, navigation, and modal functionality

## Notes

This project is a frontend prototype. Login and registration interactions are for demonstration purposes only. It does not currently include a backend, database integration, or persistent resident records.
